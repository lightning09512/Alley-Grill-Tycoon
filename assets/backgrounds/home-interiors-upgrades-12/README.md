# 12 residential interior map backgrounds

Portrait PNG backgrounds for the game's home-upgrade progression. The view stays inside the home, with the floor and furniture visible from a near-overhead game-map camera. There is no exterior facade or visible front entrance. The materials, room count, furniture and electronics improve from tier 1 to tier 12.

All images are approximately 9:16 (940–941 × 1672 px). The game selects the matching image from the current house upgrade level, preserves the artwork's aspect ratio, and follows the player with a camera bounded to the map. Keyboard and joystick controls move the player through the floor routes; broad collision zones keep the player out of the large furniture groups. Tiers 6–12 show stairs, but a separate upstairs map and stair transition still need their own map assets and game logic.
